# Image Product Search (소싱 이미지검색)

이미지 한 장을 붙여넣으면 **1688 · 타오바오 · 알리익스프레스** 이미지검색을 동시에 돌리고, 결과를 한 화면에서 비교하는 크롬 확장 프로그램입니다.

A Chrome extension (Manifest V3) that runs image search on 1688, Taobao and AliExpress at once and shows the results side by side.

## 기능
- Ctrl+V 붙여넣기 / 끌어다 놓기 / 파일 선택 / 이미지 주소 붙여넣기로 검색
- 웹페이지 이미지 우클릭 → "1688·타오바오·알리에서 이 이미지 찾기"
- 나란히 보기 / 통합 비교, 유사도·가격·판매량 정렬, 키워드·가격대 필터
- 통화 자동 구분 (위안 · 달러 · 원화 등) 후 실시간 환율로 원화 환산
- 예상 판매가·순이익 자동 계산 (설정에서 공식 변경)
  - 1688/타오바오: (원가 + 현지배송 3위안) × 200원 + 배송비부담 3,000원 → ÷ 0.64 → 100원 올림
  - 알리: 원화 가격 + 알리 배송비 부담 → ÷ 0.64 (한국 직배송)
- 제목 한국어 번역 (크롬 내장 번역, Chrome 138+)
- 최근 검색 20개 저장
- 무료: 외부 API 없이 내 크롬의 로그인 상태로 검색

## 설치
1. 이 저장소를 내려받기 (Code → Download ZIP) 후 압축 풀기
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** → 이 폴더 선택
5. 1688 · 타오바오 · 알리익스프레스에 로그인해 두기

## 구조
```
manifest.json        확장 프로그램 설정
background.js        검색 작업 관리 (탭 열기, 결과 수집)
app.html/css/js      검색·비교 화면
content/
  common.js          공통 도우미 (업로드, 통화 구분 등)
  1688*.js           1688 업로드 · 결과 읽기
  taobao*.js         타오바오 업로드 · 결과 읽기
  aliexpress*.js     알리익스프레스 업로드 · 결과 읽기
icons/               아이콘
```

## 문제 해결
- 계속 "검색 중"이면: 상태 옆 "탭 열어서 확인" → 캡차(슬라이더)나 로그인 창 확인
- 결과가 비어 있으면: 설정 → "검색 탭을 앞에 띄우기" 켜고 다시 검색
- 사이트 화면 구조가 바뀌면 `content/` 스크립트 수정 필요
- 코드 수정 후 `chrome://extensions` 에서 새로고침(↻)
